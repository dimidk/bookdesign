This is Booking OnLine Application for reservations LABS, CLASSROOMS for university units or schools.

Uses Spring Boot Authentication and MySQL for that, implemented on Java 17 and technologies
Spring Boot, JPA Hibernate, REST API

There are two roles of users: Bookers and Admin
Each user can be registered and reserve lab/classroom for a specific datetime, or for specific period like semester or
seminar. Admin user can make bulk reservations upon request.
